# 超级直达 下载

**常用操作，一键直达。** 双击 Ctrl，应用、文件、文件夹一步直达。

超级直达是一款 Windows 快速启动器：双击 Ctrl 打开应用（支持拼音首字母）、搜索文件和文件夹、执行命令；在“打开 / 保存”对话框下方一键切到资源管理器正在看的文件夹；在资源管理器和桌面里直接打字就能搜。

**下载**：到本页右侧的 [Releases](https://github.com/supergoapp/supergo-release/releases) 下载最新版本：

| 文件 | 说明 |
|---|---|
| `SuperGo-<版本>-x64-Setup.exe` | 安装包（推荐），双击安装 |
| `SuperGo-<版本>-x64-Portable.zip` | 便携版，解压即用 |

支持 Windows 10、11（64 位）。搜索文件需要 [Everything](https://www.voidtools.com/)（免费）：装了没运行时超级直达会自动启动它，没装时软件里有下载入口。功能介绍、使用教程：[超级直达官网](https://supergoapp.github.io)。

**反馈问题**：在本仓库的 [Issues](https://github.com/supergoapp/supergo-release/issues) 里提。

本仓库只放安装包和更新记录，不包含源码。

本软件采用 Vibe Coding 的方式开发（由 AI 编写代码，开发者逐项测试、修改），仅供学习和研究使用，请勿用于任何非法用途。
